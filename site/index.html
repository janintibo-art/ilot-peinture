AU QUOTIDIEN

Moins de recherche. Plus de visibilité.

Les fonctionnalités essentielles sont réunies dans une seule application pensée pour le travail en atelier.

🧴

Stocks de peinture

Enregistrer les références, les quantités, les entrées et sorties et les alertes de seuil pour peintures liquides, poudres et produits annexes.

📁

Dossiers de commandes

Rechercher par numéro, client ou emplacement. Consulter les étapes et modifier l'emplacement des dossiers.

📱

Plusieurs Android

Un serveur Linux ou NAS centralise les informations pour que les appareils de l'atelier consultent les mêmes données.

PARTICIPER AUX ESSAIS

Tester l'application

Les collègues peuvent installer l'APK de test. Un mode démonstration avec données fictives est disponible sans serveur. La connexion au serveur nécessite les paramètres fournis en interne.

  1. Appuyer sur Télécharger l'APK Android.
  2. Ouvrir le fichier APK téléchargé sur le téléphone.
  3. Autoriser l'installation depuis cette source si Android le demande, puis installer.
  4. Activer le mode démonstration pour les essais sans serveur, ou configurer l'adresse et la clé serveur transmises en privé.
  5. Tester la recherche, les dossiers et les stocks avec des données de test, pas avec des commandes réelles.

⚠️ Version de développement : ne pas utiliser pour gérer les stocks ou dossiers réels avant validation, comptes individuels, contrôles d'accès et sauvegardes opérationnelles. Installer uniquement une APK diffusée via ce site officiel du projet.
